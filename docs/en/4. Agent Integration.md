This document outlines ways to integrate with Agent Runtime: **HTTP API**, **CLI**, and **Web UI**.

# HTTP API

After **AgentApp** is running, you can call the agent over HTTP. Typical endpoints:

| Endpoint | Method | Description |
| --- | --- | --- |
| `/` | `GET` | Group info — lists mounted applications |
| `/health` | `GET` | Aggregated health check |
| `/docs` | `GET` | OpenAPI documentation |
| `/{prefix}/health` | `GET` | Health for a single app |
| `/{prefix}/query` | `POST` | AgentApp query (SSE) |
| `/{prefix}/reset_conversation` | `POST` | Reset AgentApp conversation |

## Test with curl

Assume the agent is deployed at `http://localhost:8090`.

### 1. Health check

#### Request

```bash
curl http://localhost:8090/health
```

#### Example response

```json
{
  "status": "healthy",
  "app": "CustomerService",
  "version": "1.0.0",
  "agent_loaded": true
}
```

### 2. Send a query

#### Request

```bash
curl -X POST http://localhost:8090/query \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {"role": "user", "content": "Hi, I want to check my order status"}
    ],
    "conversation_id": "conv_001",
    "user_id": "user_123"
  }'
```

- **messages:** AG-UI style messages; may include multiple turns and rich content.
- **conversation_id:** ties the session for multi-turn memory and optional state persistence.
- **user_id:** optional; pass distinct IDs if you need per-user analytics.

#### Response

The response shape is defined by the Agent implementation.

### 3. Reset conversation

#### Request

```bash
curl -X POST http://localhost:8090/reset_conversation \
  -H "Content-Type: application/json" \
  -d '{
    "conversation_id": "conv_001"
  }'
```

#### Example response

```json
{
  "status": "ok",
  "message": "Conversation conv_001 reset"
}
```

## Test with Python

```python
import asyncio
import json
import httpx

async def query_agent():
    agent_url = "http://localhost:8090"

    async with httpx.AsyncClient(timeout=30.0) as client:
        # Health check
        health = await client.get(f"{agent_url}/health")
        print(f"Health: {health.json()}")

        # Query
        request_data = {
            "messages": [
                {"role": "user", "content": "Please check order 12345"}
            ],
            "conversation_id": "conv_python_001",
            "user_id": "user_123",
        }

        # Streamed response (adapt parsing to your agent’s format)
        async with client.stream(
            "POST",
            f"{agent_url}/query",
            json=request_data,
        ) as response:
            print(f"\nAgent Response:")
            async for line in response.aiter_lines():
                if line.startswith("data: "):
                    data = line[6:]
                    try:
                        message = json.loads(data)
                        if message.get("type") == "text":
                            print(f"🤖 {message.get('content', '')}")
                        elif message.get("type") == "tool_call":
                            print(f"🔧 Tool: {message.get('tool_name', '')}")
                    except json.JSONDecodeError:
                        pass

if __name__ == "__main__":
    asyncio.run(query_agent())
```
